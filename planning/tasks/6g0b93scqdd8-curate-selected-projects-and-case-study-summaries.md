# Curate selected projects and case-study summaries

## Objective

Replace a loose mixture of links and aging project prose with a small, credible set of work that demonstrates current strengths while preserving an archive when useful.

## Acceptance criteria

- [ ] Selection criteria are applied to identify a balanced set of representative projects.
- [ ] Each selected item states the problem or context, personal contribution, outcome or significance, and a working destination where available.
- [ ] Older work is retained in an archive, summarized, or removed according to the approved information architecture.
- [ ] Images and embeds are retained only when they add evidence and have accessible text or fallback links.
- [ ] Project wording and attribution receive owner factual review.

## Out of scope

- Rebuilding third-party demos that no longer operate.
- Fabricating screenshots, outcomes, or unavailable source material.
- Turning every project into a long-form case study.
